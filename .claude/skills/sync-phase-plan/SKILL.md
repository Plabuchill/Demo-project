## เมื่อ skill นี้ถูกเรียก

1. มอบหมายให้ agent `phase-planner` ผ่าน Agent tool (`run_in_background: false` เพราะต้องเสนอแผน
   แบ่ง phase ให้ผู้ใช้ยืนยันแบบโต้ตอบผ่าน `AskUserQuestion` เสมอก่อนเขียนไฟล์จริง) พร้อมวันที่
   ปัจจุบันและบริบทว่านี่คือ session สนทนากับผู้ใช้จริง

2. **รอผลลัพธ์**: ระหว่างที่ agent เสนอแผนหรือถามคำถาม ให้ปล่อยให้ agent จัดการเอง อย่ายืนยัน/ตอบ
   แทนผู้ใช้

3. **ตรวจสอบผลลัพธ์ก่อนรายงาน**: สุ่มอ่าน `release-plan.md` และไฟล์ใน `03-task/` จริงอย่างน้อย
   1-2 จุด ตรวจว่า task ที่แตกออกมาเขียนแบบไม่ผูก tech stack

4. **สรุปให้ผู้ใช้ทราบ**: แผนที่เสนอและคำตอบยืนยัน/ปรับจากผู้ใช้, ไฟล์ที่สร้าง/แก้ไข (path เต็ม)

## ข้อควรระวัง

- ห้ามข้ามการเรียก agent แล้วเขียนไฟล์เองตรงๆ ในเทรดหลัก
- **Agent ต้องเสนอแผนแบ่ง phase ให้ผู้ใช้ยืนยันก่อนเขียนไฟล์จริงเสมอ** ถ้าผลลัพธ์แสดงว่าเขียนไฟล์
  โดยไม่มีการขอยืนยันก่อน ให้ถือว่าผิดกฎ หยุดและแจ้งผู้ใช้ทันที
- Agent ห้ามแตะไฟล์ใดๆ นอกจากใน `02-plan/`, `03-task/`, และไฟล์ log — หากผลลัพธ์พูดถึงการแก้ไข
  `feature-list.md`/เอกสารเชิงเทคนิค ให้หยุดและแจ้งผู้ใช้ทันที
- **ถ้าผลลัพธ์ระบุรายละเอียดเชิงเทคนิค/tech stack ในงานย่อยที่แตกออกมา ให้ถือว่าผิดกฎ** หยุดและแจ้ง
  ผู้ใช้ทันที
