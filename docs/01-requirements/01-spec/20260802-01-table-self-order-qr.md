# ระบบสั่งกาแฟด้วยตนเองจากโต๊ะผ่าน QR Code

> สร้างเมื่อ: 2026-08-02
> สถานะ: Draft

## ที่มา (Background)

ปัจจุบันลูกค้าที่มานั่งที่ร้านต้องเดินไปสั่งกาแฟที่เคาน์เตอร์เอง ทำให้เกิดความล่าช้าและต้องรอคิว ทางร้านต้องการให้ลูกค้าสามารถสั่งกาแฟได้เองจากโต๊ะที่นั่ง โดยไม่ต้องลุกไปที่เคาน์เตอร์

## ขอบเขต (Scope)

- ทำ:
  - ลูกค้าสแกน QR code ที่ติดอยู่บนโต๊ะ เพื่อเปิดหน้าสั่งกาแฟที่ผูกกับหมายเลขโต๊ะนั้น
  - ลูกค้าเลือกเมนู, ปรับแต่งออเดอร์ (เช่น ความหวาน/ขนาด), และยืนยันออเดอร์ผ่านหน้าเว็บที่เปิดจาก QR
  - ลูกค้าชำระเงินทันทีหลังยืนยันออเดอร์ (online payment) ก่อนออเดอร์จะถูกส่งเข้าครัว/บาร์
  - ระบบแสดงสถานะออเดอร์บนจอแสดงคิวส่วนกลาง (queue display) ในร้าน เมื่อออเดอร์ทำเสร็จ พร้อมอ้างอิงหมายเลขโต๊ะ/หมายเลขออเดอร์
- ไม่ทำ (อยู่นอกขอบเขตของ requirement นี้):
  - แอปมือถือเฉพาะของร้าน (ใช้หน้าเว็บที่เปิดผ่าน QR แทน)
  - ระบบสมาชิก/สะสมแต้ม
  - การแจ้งเตือนเฉพาะบุคคล (เช่น แจ้งเตือนผ่านมือถือลูกค้าโดยตรง) — ใช้จอแสดงคิวส่วนกลางแทน

## รายละเอียด Requirement

1. แต่ละโต๊ะมี QR code เฉพาะที่ผูกกับหมายเลขโต๊ะ เมื่อสแกนแล้วเปิดหน้าเว็บสั่งอาหารที่รู้ว่าออเดอร์นี้มาจากโต๊ะไหน โดยลูกค้าไม่ต้องติดตั้งแอปหรือสมัครสมาชิก
2. ลูกค้าเลือกเมนู เพิ่มลงตะกร้า และยืนยันออเดอร์ได้จากหน้าเว็บนี้
3. เมื่อยืนยันออเดอร์ ระบบต้องให้ลูกค้าชำระเงินออนไลน์ทันทีก่อนที่ออเดอร์จะถูกส่งเข้าคิวเตรียมเครื่องดื่ม (ออเดอร์ที่ยังไม่จ่ายเงินจะไม่ถูกส่งเข้าคิว)
4. เมื่อบาร์/พนักงานทำออเดอร์เสร็จ ต้องอัปเดตสถานะให้ปรากฏบนจอแสดงคิวส่วนกลางของร้าน เพื่อให้ลูกค้ารู้ว่าออเดอร์ของตน (อ้างอิงหมายเลขโต๊ะ/หมายเลขออเดอร์) พร้อมแล้ว

## เกณฑ์การยอมรับ (Acceptance Criteria)

- [ ] ลูกค้าสแกน QR code ที่โต๊ะแล้วเข้าสู่หน้าสั่งกาแฟที่ระบุหมายเลขโต๊ะถูกต้อง โดยไม่ต้องติดตั้งแอป/สมัครสมาชิก
- [ ] ลูกค้าสามารถเลือกเมนู ปรับแต่งออเดอร์ และยืนยันออเดอร์ได้จากหน้าเว็บ
- [ ] ออเดอร์จะไม่ถูกส่งเข้าคิวเตรียมเครื่องดื่ม จนกว่าลูกค้าจะชำระเงินออนไลน์สำเร็จ
- [ ] เมื่อออเดอร์ทำเสร็จ สถานะจะปรากฏบนจอแสดงคิวส่วนกลาง พร้อมหมายเลขโต๊ะ/หมายเลขออเดอร์ที่อ่านออก
