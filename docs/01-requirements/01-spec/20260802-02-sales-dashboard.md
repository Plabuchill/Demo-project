# Dashboard ดูยอดขาย

> สร้างเมื่อ: 2026-08-02
> สถานะ: Confirmed

## ที่มา (Background)

ปัจจุบันร้านยังไม่มีเครื่องมือสรุปยอดขายให้เจ้าของร้าน/พนักงานดูภาพรวมได้สะดวก ผู้ใช้ต้องการเพิ่ม dashboard สำหรับดูยอดขาย เพื่อช่วยติดตามผลการดำเนินธุรกิจ

> **หมายเหตุ**: requirement ดิบที่ได้รับมาในตอนแรก ("อยากเพิ่ม dashboard ดูยอดขาย") สั้นและไม่ได้ระบุรายละเอียดสำคัญหลายจุด จึงมีการสอบถามผู้ใช้เพิ่มเติมผ่าน `AskUserQuestion` และได้รับคำตอบยืนยันแล้วดังนี้:

### คำตอบที่ยืนยันจากผู้ใช้

| ประเด็น | คำตอบที่ยืนยัน |
|---|---|
| ผู้ใช้งานเป้าหมาย | เจ้าของร้าน + พนักงาน โดยมีสิทธิ์การเข้าถึงข้อมูลต่างกัน |
| มิติเวลา/ตัวกรอง | ครบทุกมิติ — เลือกช่วงเวลาได้ (วัน/สัปดาห์/เดือน/กำหนดเอง) และกรอง/แยกดูตามเมนู และตามช่องทางขาย/โต๊ะได้ด้วย |
| รูปแบบแสดงผล | กราฟ + ตัวกรองแบบ interactive เต็มรูปแบบ (เลือกช่วงเวลา/เมนู/ช่องทาง แล้วกราฟและตัวเลขอัปเดตตามทันที) |
| ความซับซ้อนของ business rule | ยอดขายรวม + จำนวนออเดอร์ + เมนูขายดี (ไม่รวมต้นทุน/กำไร เพราะยังไม่มี requirement เรื่องข้อมูลต้นทุนวัตถุดิบ) |

## ขอบเขต (Scope)

- ทำ:
  - แสดงยอดขายรวม (บาท) และจำนวนออเดอร์ทั้งหมด โดยเลือกช่วงเวลาได้ (วันนี้ / สัปดาห์นี้ / เดือนนี้ / กำหนดช่วงวันที่เอง)
  - เปรียบเทียบยอดขายกับช่วงเวลาก่อนหน้า (เช่น เทียบวันนี้กับเมื่อวาน, เดือนนี้กับเดือนที่แล้ว)
  - แสดงกราฟแนวโน้มยอดขายตามช่วงเวลาที่เลือก (กราฟเส้นหรือกราฟแท่ง) พร้อมตัวเลขสรุปประกอบ
  - มีตัวกรองแบบ interactive ให้ผู้ใช้เลือกได้พร้อมกัน 3 มิติ: ช่วงเวลา, เมนู (เลือกดูยอดขายเฉพาะเมนู หรือทุกเมนู), และช่องทางขาย/โต๊ะ (เช่น กรองเฉพาะออเดอร์จาก QR self-order ที่โต๊ะใดโต๊ะหนึ่ง หรือทุกช่องทาง) — เมื่อเปลี่ยนตัวกรอง กราฟและตัวเลขสรุปต้องอัปเดตตามทันที
  - แสดงรายการเมนูขายดี (top-selling menu) ในช่วงเวลา/ตัวกรองที่เลือก
  - จำกัดสิทธิ์การเข้าถึง: เจ้าของร้าน/ผู้บริหารเห็นข้อมูลทั้งหมด (ทุกตัวกรอง) พนักงานหน้าร้านเห็นเฉพาะยอดขายและจำนวนออเดอร์ (ไม่เห็นข้อมูลกำไร/ต้นทุน เนื่องจากยังไม่มีในระบบ)
  - นับรวมยอดขายจากทุกช่องทางที่มีในระบบปัจจุบัน (รวมถึงออเดอร์จากระบบสั่งกาแฟด้วย QR code ที่โต๊ะ ตาม [[../01-spec/20260802-01-table-self-order-qr|20260802-01-table-self-order-qr]]) และสามารถแยก/กรองดูเฉพาะช่องทางนั้นได้
- ไม่ทำ (อยู่นอกขอบเขตของ requirement นี้):
  - การคำนวณต้นทุนวัตถุดิบและกำไรสุทธิ (รอ requirement เรื่องข้อมูลต้นทุนวัตถุดิบในอนาคต)
  - การแยกยอดขายตามสาขา (ยังไม่มี requirement เรื่องระบบหลายสาขา)
  - การ export รายงานเป็นไฟล์ (เช่น Excel/PDF)
  - การแจ้งเตือน/สรุปยอดขายอัตโนมัติผ่านช่องทางอื่น (เช่น LINE, email)

## รายละเอียด Requirement

1. เจ้าของร้าน/ผู้บริหาร login เข้าระบบแล้วเข้าหน้า dashboard เพื่อดูยอดขายรวม, จำนวนออเดอร์, และกราฟแนวโน้มยอดขายของช่วงเวลาที่เลือก (วันนี้ / สัปดาห์นี้ / เดือนนี้ / กำหนดช่วงวันที่เอง)
2. ระบบต้องคำนวณและแสดงเปอร์เซ็นต์การเปลี่ยนแปลงของยอดขายเทียบกับช่วงเวลาก่อนหน้าที่มีระยะเวลาเท่ากัน (เช่น สัปดาห์นี้เทียบสัปดาห์ที่แล้ว)
3. ระบบต้องแสดงรายการเมนูขายดีอันดับต้น ๆ (top N) ในช่วงเวลา/ตัวกรองที่เลือก โดยอ้างอิงจากจำนวนที่ขายได้
4. ผู้ใช้ (ที่มีสิทธิ์เจ้าของร้าน) ต้องสามารถกรองข้อมูลยอดขายแบบ interactive ได้พร้อมกันตาม 3 มิติ: (ก) ช่วงเวลา (ข) เมนูใดเมนูหนึ่งหรือทุกเมนู (ค) ช่องทางขาย/โต๊ะใดโต๊ะหนึ่งหรือทุกช่องทาง — เมื่อปรับตัวกรองใด ๆ กราฟและตัวเลขสรุปทั้งหมดในหน้าต้องคำนวณและแสดงผลใหม่ให้ตรงกับตัวกรองที่เลือกทันที โดยไม่ต้องโหลดหน้าใหม่
5. พนักงานหน้าร้านที่ login เข้าระบบสามารถเข้าหน้า dashboard ได้ แต่เห็นเฉพาะยอดขายรวมและจำนวนออเดอร์ (พร้อมตัวกรองช่วงเวลา) ไม่เห็นตัวกรองตามเมนู/ช่องทาง และไม่เห็นข้อมูลเชิงลึกอื่น (สิทธิ์การเข้าถึงระดับ role-based)
6. ข้อมูลยอดขายที่แสดงต้องนับรวมออเดอร์จากทุกช่องทางขายที่มีในระบบ รวมถึงออเดอร์ที่มาจากการสแกน QR code สั่งกาแฟที่โต๊ะ โดยระบุหมายเลขโต๊ะ/ช่องทางของแต่ละออเดอร์ เพื่อให้กรองแยกดูตามโต๊ะ/ช่องทางได้

## เกณฑ์การยอมรับ (Acceptance Criteria)

- [ ] ผู้ใช้ที่มีสิทธิ์เจ้าของร้านสามารถเลือกช่วงเวลา (วันนี้/สัปดาห์นี้/เดือนนี้/กำหนดเอง) แล้วเห็นยอดขายรวมและจำนวนออเดอร์ของช่วงเวลานั้นถูกต้อง
- [ ] Dashboard แสดงกราฟแนวโน้มยอดขายตามช่วงเวลาที่เลือก
- [ ] Dashboard แสดงเปอร์เซ็นต์เปลี่ยนแปลงของยอดขายเทียบกับช่วงเวลาก่อนหน้าที่มีระยะเวลาเท่ากัน
- [ ] Dashboard แสดงรายการเมนูขายดี top N ของช่วงเวลา/ตัวกรองที่เลือก
- [ ] ผู้ใช้ที่มีสิทธิ์เจ้าของร้านสามารถกรองข้อมูลตามเมนูใดเมนูหนึ่ง (หรือทุกเมนู) และเห็นกราฟ/ตัวเลขสรุปอัปเดตให้ตรงกับเมนูที่เลือกทันที
- [ ] ผู้ใช้ที่มีสิทธิ์เจ้าของร้านสามารถกรองข้อมูลตามช่องทางขาย/โต๊ะใดโต๊ะหนึ่ง (หรือทุกช่องทาง) และเห็นกราฟ/ตัวเลขสรุปอัปเดตให้ตรงกับช่องทาง/โต๊ะที่เลือกทันที
- [ ] สามารถใช้ตัวกรองช่วงเวลา, เมนู, และช่องทาง/โต๊ะร่วมกันพร้อมกันได้ (ไม่ใช่เลือกได้ทีละมิติ) โดยไม่ต้องโหลดหน้าใหม่
- [ ] ผู้ใช้ที่มีสิทธิ์พนักงานเข้าหน้า dashboard ได้ แต่เห็นเฉพาะยอดขายรวมและจำนวนออเดอร์ (พร้อมตัวกรองช่วงเวลา) ไม่เห็นตัวกรองตามเมนู/ช่องทางและข้อมูลอื่นที่จำกัดสิทธิ์ไว้
- [ ] ยอดขายที่แสดงรวมออเดอร์จากช่องทาง QR self-order ที่โต๊ะด้วย และสามารถกรองแยกดูเฉพาะช่องทาง/โต๊ะนั้นได้
