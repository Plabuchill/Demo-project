# My Coffee Store — เอกสารโปรเจกต์

จุดเริ่มต้น (entry point) ของฐานความรู้ทั้งหมดของโปรเจกต์ เอกสารถูกจัดเรียงตามลำดับการไหลของงาน (pipeline) ตั้งแต่ต้นน้ำถึงปลายน้ำ:

1. [[01-requirements/index|01-requirements]] — ความต้องการของโปรเจกต์ (spec, plan, task)
2. [[02-design/index|02-design]] — การออกแบบ UI/UX และเทคนิค ต่อยอดจากความต้องการ
3. [[03-testing/index|03-testing]] — แผนการทดสอบและผลการทดสอบ อ้างอิงจากการออกแบบ
4. [[04-retrospectives/index|04-retrospectives]] — สรุปบทเรียนหลังจบแต่ละ phase/sprint
5. [[05-log/index|05-log]] — บันทึกความเคลื่อนไหวและการตัดสินใจตามลำดับเวลา
6. [[00-archived/index|00-archived]] — เอกสารที่เลิกใช้งานแล้ว (ย้ายมาเก็บแทนการลบ)

> แต่ละโฟลเดอร์มี `index.md` อธิบายจุดประสงค์และลิงก์ไปยังโฟลเดอร์ที่เกี่ยวข้องด้วย wiki-link ให้เริ่มอ่านจากลำดับด้านบนเพื่อเข้าใจภาพรวมของโปรเจกต์
